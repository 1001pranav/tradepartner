# M0: Scaffold, done

## What exists
- `uv` project (Python 3.12), layout from spec section 5 (packages only; no future-milestone logic).
- `config/*.yaml` with the spec defaults, loaded and validated by `settings.py` (strict pydantic: unknown keys rejected).
- Startup gate: `require_ready()` refuses to run while `risk.capital_base_inr` is 0.
- Config guards: 1 order/s and 30 orders/day hard caps, AUTO-only limits cannot be looser than the general ones, UI host must be `127.0.0.1`, segments limited to `NSE_EQ`.
- structlog JSON logging with secret redaction, daily-rotated file under `~/.tradepartner/logs/`.
- SQLAlchemy 2.0 models for every table in spec section 6; Alembic migration `0001`. WAL and foreign keys are on. Timestamps are UTC (naive datetimes rejected), money is integer paise, CHECK constraints enforce enums.
- Append-only tables (`fills`, `news_raw`, `news_scores`, `signals`, `order_events`, `charges`, `cash_ledger`, `risk_events`, `audit_log`) reject UPDATE and DELETE via SQLite triggers.
- Typer CLI skeleton (`check`, `db upgrade`, `kill` work; the rest are stubs naming their milestone).
- import-linter contract: strategies, models, llm, signals, features and news cannot import `execution.router` or `modes.controller`.
- pre-commit config (ruff, mypy, import-linter) and 41 tests (100% branch coverage).
