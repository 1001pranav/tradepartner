# M1: Market data, done

## What exists
- `calendar.py`: NSE trading calendar (weekends + `config/holidays.yaml`), session times in IST, FY helpers.
  **The holiday list is a starting point and must be checked against the NSE circular each year [VERIFY].**
- `data/kite_auth.py`: manual login only. A redirect server on `127.0.0.1` captures the `request_token`; api key, secret and the daily access token live in the macOS Keychain. Tokens older than today are treated as missing.
- `data/instruments.py`: Kite instrument master -> `instruments`, NSE equity only.
- `data/universe.py`: point-in-time `universe_members`, seeded from `config/universe/nifty100.csv` (**approximate current list [VERIFY]; static membership prints a survivorship warning**).
- `data/candles.py`: token-bucket limiter (self-limited to 2 req/s), chunked, retrying, resumable backfill; Parquet store (`<root>/<interval>/<symbol>.parquet`, atomic writes) queried with DuckDB; gap detection. Prices are integer paise. A daily bar's `ts` is the session close, so `as_of` filtering cannot leak.
- `data/corporate_actions.py`: CSV import (idempotent, strict columns) and split/bonus price adjustment. Raw prices are stored; adjusted ones are derived.
- `data/quality.py`: duplicate/sorting/OHLC/negative/zero-volume/gap checks and unexplained-jump detection.
- CLI: `login`, `data instruments|seed-universe|actions-import|backfill|quality`.

## Acceptance
- Backfill resumes after interruption and only fetches the missing range (tests).
- Quality checks pass on clean fixtures and flag every defect class.
- Adjusted prices are continuous across a 5:1 split fixture.

## Notes
- Not exercised against live Kite (tests mock it). Run `tradepartner login` then `tradepartner data backfill --universe nifty100 --years 10` yourself.
- Corporate actions are not auto-downloaded (Kite has no endpoint). Import them from a CSV; the quality report flags missing ones as `unexplained_jump`.
- Index tokens (`NIFTY 50` 256265, `INDIA VIX` 264969) are in `data/kite_client.py` [VERIFY].
