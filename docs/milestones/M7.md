# M7: Signals, explanations, UI and MANUAL flow, done (the 10-day unattended run is yours to do)

## What exists
- `strategies/`: `ModelStrategy` (swing_v1, positional_v1) ranks the universe with the approved LightGBM model, then builds entry/stop/target from ATR geometry. It also returns the top-5 LightGBM feature contributions for the explanation. Quantity is never part of it.
- `signals/generate.py`: signals are append-only; geometry and lifecycle live in append-only `signal_events` (migration 0005). Shadow models log signals but never explain or show them. Re-runs are idempotent.
- `signals/explain.py`: the LLM writes 3-5 sentences from the top drivers, scored news and price context. **Every number in the answer must appear in the facts it was given**; otherwise one retry, then a deterministic template built only from those facts. So every shown explanation passes the number check.
- `signals/proposals.py`: at 09:20 each fresh signal becomes a proposal through the router (risk engine + mode controller). Signal code talks to a `Submitter` protocol and cannot import `execution.router` (import-linter caught my first draft doing exactly that).
- `signals/outcomes.py`, `signals/shadow.py`: outcomes are revealed after the horizon; shadow candidates are compared with the approved model.
- `jobs.py` + `scheduler.py`: the whole spec 12 schedule (19 jobs), IST, trading days only, `heavy_job` lock between LLM scoring/signal generation and training, `job_runs` rows, errors never kill the scheduler, catch-up after sleep for idempotent jobs only (**`submit_entries` is never caught up** and the signal-age rule enforces it again).
- `data/quotes.py` (Kite quote polling with circuit flags), `data/meta.py` (ADV, sector, ASM/GSM list in `config/asm_gsm.csv`, results/ex-dates), `reports/daily.py`, `ops/` (launchd plist, backup.sh, static-IP notes).
- UI: Today (status, kill switch, signals with explanations and risk reasons, **Copy order for Kite** with the exact order and GTT values, Ignore), Positions, System.
- CLI: `run`, `job list|run`, `news ...`, `train`, `models ...`.
